SSL Checker は、現在のタブで開いているサイトの TLS 証明書（お使いのブラウザが実際に受け取った証明書）を表示し、ブラウザとサイトの間にある何かがその証明書を置き換えていないかを知らせます。

【表示される情報】
• 証明書: 名前、発行元、有効期間、認証レベル（DV、OV、EV）、鍵と署名のアルゴリズム。
• 接続: TLS バージョン、鍵交換（ポスト量子ハイブリッド方式を含む）、暗号方式、Encrypted Client Hello、Certificate Transparency。
• 完全な証明書チェーン、フィンガープリント、シリアル番号、すべての拡張領域。PEM のコピーやチェーンのダウンロードもできます。

【傍受を見破る】
SSL Checker は、PlusPrivacy 公証サーバーと追加したすべての公証サーバーに、インターネット上の別の場所から見て同じサイトがどの証明書を提示しているかを問い合わせ、比較します:
• どこでも同じ証明書 → 確認済み。
• お使いの証明書が異なり、公開ログに記録されていない → お使いの HTTPS 通信は復号され、再署名されています（企業のプロキシ、ウイルス対策ソフト、またはもっと悪質なもの）。SSL Checker は、置き換え用の証明書を発行した認証局の名前を表示します。

【確認したサイトを記憶】
SSL Checker は各サイトの認証局を記憶し、既知のサイトで突然別の認証局が使われたときに警告します。記憶はお使いのデバイス上にとどまり、シークレット ウィンドウは一切記録されません。

【デバッガを実行するタイミングを選べます】
Chrome には読み込まれたページの証明書を取得する API がないため、SSL Checker は Chrome のデバッガを約 1 秒間タブにアタッチします。その間、Chrome にはデバッグ通知バーが表示されます。オプション ページで、毎回・必要なときのみ・読み取らない（公証サーバーのみ）から選べます。

【署名付きの応答】
PlusPrivacy 公証サーバーはすべての応答に署名し、SSL Checker がその署名を検証するため、途中で誰も確認結果を偽造できません。公証サーバーはオープンソースです。独自に運用し、その鍵とともに追加できます。

【プライバシー】
アナリティクスなし、トラッキングなし、アカウント不要。初めて確認する前に、SSL Checker は何を読み取り、何を送信するかを説明し、同意を求めます。お使いのデバイスから送信されるのは、確認したサイトのホスト名とポート番号だけで、送信先は公証サーバーです。PlusPrivacy 公証サーバーはこれらの記録を残さず、オフにすることもできます。
